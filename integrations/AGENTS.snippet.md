## Cobros con CoDi / pey

Cuando la tarea involucre cobrar con CoDi, la API de pey (pey.mx), links de pago, cuentas CLABE por tenant o webhooks de pey:

1. Lee primero `.agents/skills/pey-codi-integration/SKILL.md` (ajusta la ruta si instalaste el skill en otra carpeta).
2. Según el stack del proyecto, lee después `references/laravel.md` o `references/node-typescript.md` de esa misma carpeta.
3. Antes de escribir código, vuelve a leer la spec https://docs.pey.mx/openapi.json; si difiere del skill, manda la spec.
4. Cierra con la sección "Definition of done" de `SKILL.md`.
